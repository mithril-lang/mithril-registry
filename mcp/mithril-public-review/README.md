# Mithril Public Code Review (mcp)

This surface composes the `mithril-public-review` skill, plugin, agent, workflow and MCP into the existing Mithril Agent/Desktop profile flow. Runtime artifact: [eab517f](https://github.com/mithril-lang/mithril-system-one/tree/eab517fdd2fd22848b23280cbbecbe875cd4c6bf). [Execution contract and installation](https://github.com/mithril-lang/mithril-system-one/blob/eab517fdd2fd22848b23280cbbecbe875cd4c6bf/docs/public-code-review-bot.md).

Input: public `owner/repository` plus an exact 40-character commit. The tool verifies source provenance, parses a bounded JavaScript/TypeScript ESM/CommonJS child_process subset and executes `.mith` ontology policies. It also acquires supported npm lockfiles, resolves full OSV advisories, invokes a pinned operator-owned private version matcher, and enriches through Knowledge. Knowledge currently returns 503 in live qualification; enrichment remains unknown. Result is always `review_incomplete`; candidates require human review. No target code execution, inference, private repository access, GitHub writes or disclosure.

The `mithril-public-code-review` bot profile uses English and api.mithril.fund for future conversations. Install it with the artifact's `scripts/install-public-review-profile.py --home /absolute/hermes/home --apply`; credentials belong to that profile and are configured separately. No active-profile switch, gateway startup or scheduled jobs occur. Deterministic tool readiness is verified; a live provider conversation is qualified for the independently configured operator profile.

Native Agent tested on macOS with 0.21.5+4485.g3da66ca.dirty. Linux compatibility is not qualified. MCP is local stdio 2025-06-18, not a hosted URL. Workflow runs exactly one immutable repository review and stops on failure/unknown without retries.

Dependency setup requires separately authorized private `security-core` access; no proprietary source is distributed. See the [dependency runtime contract](https://github.com/mithril-lang/mithril-system-one/blob/eab517fdd2fd22848b23280cbbecbe875cd4c6bf/docs/dependency-ontology-evaluation.md). Missing/stale feeds never mean safe; no automatic upgrades or SCAP execution. The upgraded tool was qualified through native Agent dispatch; the model-conversation qualification predates this dependency release.
