# Evidence-backed report

Verify the original retained run bytes through the query tools. Select only authorized runs, then call cybersecurity_export into a new private directory. This bundle includes normalized claims and source hashes, not original source files or a trusted vendor signature. Keep original runs available separately.

Write the report around the question, dated observations, vendor claims, your inferences and unresolved evidence. Every material observation should identify product, sourceSha256 and sourceRow; include vendor ID when available. Document collection mode, pagination, unknown timestamps, vendor qualification and asset mapping provenance.

Inspect confidential fields before sharing. The tool does not redact and creates no public link. Sharing or cloud upload requires the relevant existing authorization. Empty samples, sampleAbsent, successful hash verification and fixture-tested adapters do not prove that a system is clean or a vendor result authentic.
